# Padding creates breathing room

Padding belongs **inside** an element. It separates content from the border and contributes to the rendered size under the default box model.

## What padding changes

Increase padding when content needs room to breathe. Do not use it to create distance between sibling elements; that is margin's job.

## Try a prediction

Imagine a button with a fixed content width. Predict its final width after adding 16 pixels of padding on both sides, then verify your arithmetic.
