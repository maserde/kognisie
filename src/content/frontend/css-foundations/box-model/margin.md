# Margin separates neighbors

Margin is transparent space **outside** the border. It changes how an element relates to nearby elements without enlarging its painted background.

## Relationship, not decoration

Use margin to express separation between peers. When spacing belongs to a parent layout, prefer the layout's `gap` property so the relationship stays centralized.
