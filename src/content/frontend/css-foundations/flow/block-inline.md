# Block and inline flow

Normal flow is the browser's default placement algorithm. Understanding it removes much of the mystery from CSS layout.

## Block flow

Block elements typically claim the available inline width and stack along the block axis.

## Inline flow

Inline content participates in lines. Width and height do not behave like block dimensions because text flow remains in charge.
